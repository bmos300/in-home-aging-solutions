# In Home Aging Solutions, PLLC

Website source exported from the latest saved Sites repository on November 2, 2026.
Source commit: d34f3264de6ff156aa300e4e34c55a302830ade5.

## Run locally

No installation or build is required. With Python installed, run:

```sh
python -m http.server 8000 --directory dist
```

Then visit http://localhost:8000.

## Deploy to Vercel

Import this repository, select Other as the framework, leave the build command empty, and set the output directory to `dist`.
Add `inhomeagingsolutions.com` in the project's domain settings and follow the DNS instructions Vercel provides.

## Files

- `dist/index.html`: page content
- `dist/styles.css`: styles
- `dist/app.js`: interactive behavior
- `dist/assets/`: images and graphics
- `dist/downloads/`: downloadable client profile PDF
- `.openai/hosting.json`: original Sites project identity

## GitHub

Create an empty GitHub repository, then run these commands from this folder, replacing YOUR-USERNAME with your GitHub username:

```sh
git remote add origin https://github.com/YOUR-USERNAME/in-home-aging-solutions.git
git push -u origin main
```

This download includes an initialized Git repository and its initial commit. It has no GitHub remote configured.
